`interpret` is a method on the [`MachineDefinition`](/effstate/api/define-machine/)
that yields a running [`MachineActor`](#machineactor).

## interpret

```ts
machine.interpret(
  options?: InterpretOptions<S, C, Err>,
): Effect.Effect<MachineActor<S, C, E>, never, R>;
```

Returns an Effect that produces the actor. It **never fails** — effect errors
during `entry` / `exit` / `run` surface through `onError` instead of the error
channel.

The Effect requires `R`. When `R = never`, run it synchronously with
`Effect.runSync`; when the machine needs services, provide a `Layer` first.

```ts
import { Effect } from "effect";

// R = never
const actor = Effect.runSync(stopwatch.interpret());

// R needs services
const actor2 = Effect.runSync(machine.interpret().pipe(Effect.provide(SomeLayer)));
```

## InterpretOptions

```ts
interface InterpretOptions<S, C, Err = never> {
  snapshot?: MachineSnapshot<S, C>;
  onError?: (error: MachineEffectError<Err>) => void;
  interruptEntryOnTransition?: boolean; // default false
}
```

- `snapshot?` — restore from a saved `MachineSnapshot` instead of the initial state/context.
- `onError?` — called when an `entry` / `exit` / `run` effect fails. Without it,
  errors are `console.error`'d.
- `interruptEntryOnTransition?` — default `false`: entry effects run to completion
  even when the machine transitions away. `true`: interrupt them on transition.
  (Entry effects are always interrupted on `stop()`; run streams are always
  interrupted on exit; exit effects are fire-and-forget.)

## MachineEffectError

```ts
interface MachineEffectError<Err = never> {
  readonly _tag: "MachineEffectError";
  readonly effectType: "entry" | "exit" | "run";
  readonly stateTag: string;
  readonly cause: Cause.Cause<Err>;
}
```

The value passed to `onError`, describing which effect failed and why.

## MachineActor

```ts
interface MachineActor<S, C, E> {
  send(event: E): void;
  getSnapshot(): MachineSnapshot<S, C>;
  subscribe(observer: (snapshot: MachineSnapshot<S, C>) => void): () => void;
  stop(): void;
  _syncSnapshot(snapshot: MachineSnapshot<S, C>): void;
}
```

- `send(event)` — dispatch an event.
- `getSnapshot()` — read the current `{ state, context }`.
- `subscribe(observer)` — observe snapshot changes; returns an unsubscribe function.
- `stop()` — interrupt fibers, run the final exit, and clear subscribers.
- `_syncSnapshot(snapshot)` — **advanced.** Set the snapshot from an external source
  (persistence / cross-tab). Triggers `exit` / `entry` effects if the state tag changed.

## Example

```ts
import { Effect } from "effect";
import { stopwatch, Start, Stop, Reset } from "./stopwatch";

const actor = Effect.runSync(
  stopwatch.interpret({
    onError: (err) => console.error(err.effectType, err.stateTag, err.cause),
  }),
);

const unsubscribe = actor.subscribe((snap) =>
  console.log(snap.state._tag, snap.context.elapsed),
);

actor.send(Start.make()); // ticks begin; elapsed increments each second
actor.send(Stop.make());  // ticks auto-cancel
actor.send(Reset.make()); // global handler → Idle, elapsed 0

unsubscribe();
actor.stop();
```
