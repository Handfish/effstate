The type-level building blocks exported by `@handfish/effstate-v4`. Import them
with `import type`.

## Constraint types

These are the base shapes the machine generics extend.

```ts
import type { MachineState, MachineEvent, MachineContext } from "@handfish/effstate-v4";
```

- `MachineState` — `{ readonly _tag: string }`; the minimum shape of a state.
- `MachineEvent` — the minimum shape of an event (a tagged object).
- `MachineContext` — `object`; the constraint on a context type.

## Tag helpers

```ts
import type { StateTag, StateByTag, EventByTag } from "@handfish/effstate-v4";

type Tags = StateTag<StopwatchState>;              // "Idle" | "Running"
type RunningState = StateByTag<StopwatchState, "Running">;
type StartEvent = EventByTag<StopwatchEvent, "Start">;
```

- `StateTag<S>` — the union of state `_tag` literals in `S`.
- `StateByTag<S, K>` — the state member of `S` whose tag is `K`.
- `EventByTag<E, K>` — the event member of `E` whose tag is `K`.

## Snapshot & runtime types

```ts
import type {
  MachineSnapshot,
  MachineActor,
  MachineDefinition,
} from "@handfish/effstate-v4";
```

- `MachineSnapshot<S, C>` — `{ state: S; context: C }`; the observable machine value.
- `MachineActor<S, C, E>` — the running actor. See [MachineActor](/effstate/api/interpret/#machineactor).
- `MachineDefinition<S, C, E, R, Err>` — the definition returned by
  [`defineMachine`](/effstate/api/define-machine/).

## Extractors

Recover the generic parameters from a `MachineDefinition` type — useful when
sharing a machine across modules.

```ts
import type {
  MachineStateType,
  MachineContextType,
  MachineEventType,
  MachineRequirements,
  MachineError,
} from "@handfish/effstate-v4";

type M = typeof stopwatch;

type S = MachineStateType<M>;    // StopwatchState
type C = MachineContextType<M>;  // StopwatchContext
type E = MachineEventType<M>;    // StopwatchEvent
type R = MachineRequirements<M>; // Effect requirements (never here)
type Err = MachineError<M>;      // entry/exit/run error channel (never here)
```

- `MachineStateType<T>` — the state union `S`.
- `MachineContextType<T>` — the context type `C`.
- `MachineEventType<T>` — the event union `E`.
- `MachineRequirements<T>` — the Effect requirements `R`.
- `MachineError<T>` — the error channel `Err`.
