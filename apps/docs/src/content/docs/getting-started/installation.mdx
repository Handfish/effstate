## Prerequisites

- **Node.js** 18 or newer
- **TypeScript** 5.0 or newer
- **`effect`** `^3` — a peer dependency you install yourself

## Install the core

```bash
npm install @handfish/effstate-v4 effect
```

```bash
pnpm add @handfish/effstate-v4 effect
```

<Aside type="note">
`effect` is a peer dependency, not bundled. Installing it explicitly lets you control the
Effect version and share a single copy across your app.
</Aside>

## React bindings (optional)

For the React hooks (`useActor`, `useActorBridge`, and friends), add the bindings package.
It requires React 18+ alongside the core and `effect`.

```bash
npm install @handfish/effstate-react @handfish/effstate-v4 effect react
```

```bash
pnpm add @handfish/effstate-react @handfish/effstate-v4 effect react
```

## TypeScript configuration

effstate relies on strict inference. A minimal `tsconfig.json`:

```json
{
  "compilerOptions": {
    "strict": true,
    "moduleResolution": "bundler",
    "module": "ESNext",
    "target": "ES2022"
  }
}
```

<Aside type="tip">
`"moduleResolution": "bundler"` suits Vite, esbuild, and most modern bundlers. If you run
directly under Node's ESM resolver, use `"nodenext"` instead (with a matching
`"module": "nodenext"`).
</Aside>
