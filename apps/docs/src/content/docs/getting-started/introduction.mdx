**effstate v4** is a lean library for building typed, schema-first state machines on top of
[Effect](https://effect.website). States and events are declared once as discriminated
unions with schemas; transitions patch a plain context object; and every side effect is a
real `Effect` — with its full requirements (`R`) and error channel intact.

## Philosophy

<CardGrid>
  <Card title="Schema-first" icon="document">
    A single `State(...)` / `Event(...)` definition is the source of truth: it produces the
    TypeScript type, a runtime constructor, a type guard, and an Effect `Schema` codec.
  </Card>
  <Card title="Effect-native" icon="rocket">
    Entry/exit effects and run streams are ordinary `Effect`s and `Stream`s. Requirements
    flow through `R` and are provided with layers; errors flow through a real error channel.
  </Card>
  <Card title="Honest errors" icon="warning">
    Effect failures aren't swallowed. Supply `onError` at interpret time to observe every
    entry/exit/run failure as a structured `MachineEffectError`.
  </Card>
  <Card title="Minimal" icon="star">
    Roughly ~500 LOC with zero dependencies beyond Effect (`effect` is a peer dependency).
    No hidden runtime, no bespoke DSL layered on top of Effect.
  </Card>
</CardGrid>

## Core concepts

**States & Events** — declared with `State(tag, fields)` and `Event(tag, fields)` (`Event`
is a semantic alias of `State`). Each returns a definition exposing `.make()`,
`.safeMake()`, `.is()`, `.schema`, and `.tag`. A machine's state or event type is a plain
union of these variant instances.

**Context** — a plain immutable object carrying data that isn't part of the state's
identity. Transitions patch it with a shallow `update`. Pass an optional `context` `Schema`
when you need validation or serialization.

**Transitions** — an `on` handler is `(ctx, event) => Transition`. It returns `{ goto }` to
move states, `{ update }` to patch context, `{ actions }` for fire-and-forget sync work, any
combination of `goto`/`update`/`actions`, or `null` to do nothing (which is also how you
express a guard).

**Effects** — per-state `entry` and `exit` effects plus a `run` stream that emits events
while the state is active and auto-cancels on exit. All are fully typed `Effect`s/`Stream`s.

**Actor** — the running instance produced by `interpret()`. It exposes `send`,
`getSnapshot`, `subscribe`, and `stop`.

## A taste

```ts
import { State, Event, defineMachine } from "@handfish/effstate-v4";
import type { StateType, EventType } from "@handfish/effstate-v4";
import { Schema, Effect, Stream, Duration, Schedule } from "effect";

const Idle = State("Idle", {});
const Running = State("Running", { startedAt: Schema.DateFromSelf });

type StopwatchState = StateType<typeof Idle> | StateType<typeof Running>;

const Start = Event("Start", {});
const Stop = Event("Stop", {});
const Tick = Event("Tick", {});
const Reset = Event("Reset", {});

type StopwatchEvent =
  | EventType<typeof Start>
  | EventType<typeof Stop>
  | EventType<typeof Tick>
  | EventType<typeof Reset>;

interface StopwatchContext {
  readonly elapsed: number;
}

// A run stream: one Tick per second, auto-cancelled when leaving Running
const ticks = Stream.fromSchedule(Schedule.spaced(Duration.seconds(1))).pipe(
  Stream.map(() => Tick.make()),
);

export const stopwatch = defineMachine<StopwatchState, StopwatchContext, StopwatchEvent>({
  id: "stopwatch",
  initialState: Idle.make(),
  initialContext: { elapsed: 0 },
  states: {
    Idle: {
      on: {
        Start: () => ({ goto: Running.make({ startedAt: new Date() }) }),
      },
    },
    Running: {
      entry: (snap) => Effect.log(`Started at ${snap.state.startedAt.toISOString()}`),
      run: ticks,
      on: {
        Tick: (ctx) => ({ update: { elapsed: ctx.elapsed + 1 } }),
        Stop: () => ({ goto: Idle.make() }),
      },
    },
  },
  global: {
    Reset: () => ({ goto: Idle.make(), update: { elapsed: 0 } }),
  },
});
```

<Aside type="note">
`effect` is a peer dependency — install it alongside the core package. `Schema`, `Effect`,
`Stream`, and `Either` are re-exported from `@handfish/effstate-v4` for convenience, but
utilities like `Duration`, `Schedule`, and `Layer` are imported from `"effect"` directly.
</Aside>
