This guide builds a **Stopwatch** machine from scratch — states, events, a run stream,
transitions — then interprets it and wires it into React.

## 1. Define states

States are a schema-first discriminated union. Each `State(tag, fields)` gives you a
constructor, a guard, and a schema. Data that identifies the state (like `startedAt`) lives
on the state itself.

```ts
import { State } from "@handfish/effstate-v4";
import type { StateType } from "@handfish/effstate-v4";
import { Schema } from "effect";

const Idle = State("Idle", {});
const Running = State("Running", { startedAt: Schema.DateFromSelf });

type StopwatchState = StateType<typeof Idle> | StateType<typeof Running>;
```

## 2. Define events

`Event` is a semantic alias of `State`. Events carry the data a transition needs; here they
carry none.

```ts
import { Event } from "@handfish/effstate-v4";
import type { EventType } from "@handfish/effstate-v4";

const Start = Event("Start", {});
const Stop = Event("Stop", {});
const Tick = Event("Tick", {});
const Reset = Event("Reset", {});

type StopwatchEvent =
  | EventType<typeof Start>
  | EventType<typeof Stop>
  | EventType<typeof Tick>
  | EventType<typeof Reset>;
```

## 3. Define the context

Context is a plain object for data that isn't part of the state's identity — here, the
elapsed second count.

```ts
interface StopwatchContext {
  readonly elapsed: number;
}
```

## 4. Create a run stream of Ticks

A `run` stream emits events while its state is active and is **auto-cancelled on exit**.
This one emits one `Tick` per second.

```ts
import { Stream, Duration, Schedule } from "effect";

const ticks = Stream.fromSchedule(Schedule.spaced(Duration.seconds(1))).pipe(
  Stream.map(() => Tick.make()),
);
```

## 5. Define the machine

`defineMachine` ties it together: the initial state and context, per-state config (`entry`,
`run`, `on`), and `global` handlers that apply in any state.

```ts
import { defineMachine } from "@handfish/effstate-v4";
import { Effect } from "effect";

export const stopwatch = defineMachine<StopwatchState, StopwatchContext, StopwatchEvent>({
  id: "stopwatch",
  initialState: Idle.make(),
  initialContext: { elapsed: 0 },
  states: {
    Idle: {
      on: {
        Start: () => ({ goto: Running.make({ startedAt: new Date() }) }),
      },
    },
    Running: {
      entry: (snap) => Effect.log(`Started at ${snap.state.startedAt.toISOString()}`),
      run: ticks,
      on: {
        Tick: (ctx) => ({ update: { elapsed: ctx.elapsed + 1 } }),
        Stop: () => ({ goto: Idle.make() }),
      },
    },
  },
  global: {
    Reset: () => ({ goto: Idle.make(), update: { elapsed: 0 } }),
  },
});
```

<Aside type="note">
A `global` handler runs only when the current state has no matching `on` handler for that
event. That's why `Reset` works from both `Idle` and `Running`.
</Aside>

## 6. Interpret and use

`interpret()` is a method returning an `Effect`. With no service requirements (`R = never`)
you can run it synchronously to get the actor.

```ts
import { Effect } from "effect";

const actor = Effect.runSync(stopwatch.interpret());

const unsubscribe = actor.subscribe((snap) =>
  console.log(snap.state._tag, snap.context.elapsed),
);

actor.send(Start.make()); // ticks begin; elapsed increments each second
actor.send(Stop.make());  // ticks auto-cancel
actor.send(Reset.make()); // global handler → Idle, elapsed 0

unsubscribe();
actor.stop();
```

<Aside type="tip">
If the machine needs services (`R`), provide a `Layer` before running:
`Effect.runSync(stopwatch.interpret().pipe(Effect.provide(MyLayer)))`.
</Aside>

## 7. Use with React

`useActor` creates and owns the actor, subscribes via `useSyncExternalStore`, and stops it
on unmount. It returns `snapshot`, `state`, `context`, `stateTag`, `send`, and `actor`.

```tsx
import { useActor } from "@handfish/effstate-react";
import { stopwatch, Start, Stop, Reset } from "./stopwatch";

function Stopwatch() {
  const { stateTag, context, send } = useActor(stopwatch);
  return (
    <div>
      <h1>{context.elapsed}s</h1>
      {stateTag === "Idle"
        ? <button onClick={() => send(Start.make())}>Start</button>
        : <button onClick={() => send(Stop.make())}>Stop</button>}
      <button onClick={() => send(Reset.make())}>Reset</button>
    </div>
  );
}
```

<Aside type="caution">
`useActor` runs `interpret()` with `Effect.runSync`, so it's for machines with `R = never`.
Machines that need services must be pre-provided before they reach the component.
</Aside>
